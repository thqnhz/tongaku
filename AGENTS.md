# Agents guidance for Tongaku

Tongaku is a Linux only YouTube Music client written in Rust using GPUI-kit.

## Skills

Use [`gpui-kit`](.agents/skills/gpui-kit) and [`gpui-kit-design-guides`](.agents/skills/gpui-kit-design-guides) when doing jobs related to GPUI-kit.

## Commands

- `make lint` to run `cargo fmt` and `cargo clippy` for debugging.

## Must do

- Split the project to small crates for maintainability and stability.
- You are to follow best Rust practices.
